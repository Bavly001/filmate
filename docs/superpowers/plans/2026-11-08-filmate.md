# Filmate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Filmate, a dark-neon movie showcase and intelligent AI-style recommendation web application featuring real trailers, streaming badges, and the zero-typing "Mate" companion with progressive category relaxation.

**Architecture:** Next.js 14 App Router single-page application with Tailwind CSS (Electric Sunset theme), Zustand for quiz and session state, TanStack Query for keyless public KinoCheck trailer fetching, and a rich local dataset (120+ movies) ensuring 100% resilience and instant recommendations.

**Tech Stack:** Next.js 14, TypeScript, Tailwind CSS, Zustand, TanStack Query v5, Framer Motion, Lucide React, Vitest / React Testing Library.

**Spec:** `docs/superpowers/specs/2026-11-08-filmate-design.md`

## Global Constraints
- **Color Palette (Electric Sunset):** Background `#08070d`, Primary Tangerine `#ff6b2b`, Cyber-Violet `#e040fb`, Gold Amber `#ffa726`, Smoky Glass `#12111a`.
- **Zero Freeform Typing:** The Mate companion uses only interactive choice pills; no text input fields for the chat.
- **Simulated Loader:** Minimum artificial delay of 2.5s–3.5s before showing movie recommendations.
- **Git Attribution:** Solely to `Bavly001` (Bavly). No AI attribution or `Co-Authored-By` lines.

## Review Focus
1. **Empty Intersection Handling:** When a user picks uncommon moods (e.g. Horror + Romance), the candidate pool may be empty on first attempt; verify graceful immediate fallback to the primary mood without crashing.
2. **Repeat Recommendation Prevention:** Declining a movie adds its ID to `seenMovieIds`; verify that movie is never recommended again in the same session.
3. **Category Relaxation Progression:** Verify that when a pool is exhausted, the engine removes only the last category from `[A, B, C]` → `[A, B]` → `[A]` and broadens the search.
4. **All-Exhausted State:** When all matching titles across all relaxed categories are exhausted, verify the clear message: *"Sorry mate, we've exhausted all matching movies..."*.
5. **Offline/Network Failure on KinoCheck API:** If the external trailer feed fails, verify the application transparently falls back to curated trailer keys without blocking the UI.

import { describe, it, expect, beforeEach } from 'vitest';
import { useMateStore } from './useMateStore';

describe('Mate Store Recommendation Engine', () => {
  beforeEach(() => {
    useMateStore.getState().resetQuiz();
  });

  it('enforces All Ages if Family & Kids company is chosen', () => {
    const store = useMateStore.getState();
    store.setCompany('family');
    expect(useMateStore.getState().preferences.ageRating).toBe('All Ages');
  });

  it('excludes rejected movie and delivers another match', () => {
    const store = useMateStore.getState();
    store.toggleMood('Action');
    store.computeRecommendation();
    const firstMovie = useMateStore.getState().currentRecommendation;
    expect(firstMovie).not.toBeNull();

    store.rejectRecommendation();
    const seen = useMateStore.getState().seenMovieIds;
    expect(seen).toContain(firstMovie!.id);
    const secondMovie = useMateStore.getState().currentRecommendation;
    if (secondMovie) {
      expect(secondMovie.id).not.toBe(firstMovie!.id);
    }
  });

  it('relaxes categories when active pool runs out', () => {
    const store = useMateStore.getState();
    useMateStore.setState({ activeCategories: ['Drama', 'Comedy', 'Romance'] });
    store.relaxCategories();
    expect(useMateStore.getState().activeCategories).toEqual(['Drama', 'Comedy']);
  });
});
